# מיפוי להוראות המרצה

| דרישה | מימוש במחברת |
|---|---|
| נתונים טבלאיים שאינם מאגר הדגמה פשוט | Telecom: 7,043 שורות, 21 עמודות מקוריות |
| טעינה, המחשה, groupby וסיפור הנתונים | בדיקות איכות, שיעורי נטישה לפי קבוצות, התפלגות ותק ומפת חום |
| הנדסת תכונות ובדיקת תרומה | SubscribedServiceCount והשוואת מודלים עם ובלי התכונה |
| Random Forest ו־AdaBoost | השוואת מסווגים בטבלת התיקוף |
| מסווג נוסף | Logistic Regression; בנוסף מודלי הצבעה |
| צמצום ממדים וחזרה על המסווגים | PCA השומר לפחות 95% מהשונות בתכונות המעובדות |
| עיבוד לא מפוקח וחזרה על המסווגים | KMeans ובחירת מספר אשכולות לפי silhouette באימון |
| התוצאה הטובה ביותר | בחירה לפי F1 בתיקוף ומדידה סופית על חלק בדיקה נפרד |

המסמך מתאר כיסוי טכני של הסעיפים, ואינו מהווה אישור של המרצה או הערכת ציון. ההוראות המקוריות נמצאות ב־assignment.pdf.
